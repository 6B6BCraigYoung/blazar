## b1 · 视觉打底

对应第 0 条（好看），兼顾 3（内容优先）、4（一致）、5（细节）。几乎只改样式，逻辑只动了中控台页头和对话里的工作区标签。

- **设计令牌收敛**：字号从 17 档收到 11 / 12 / 13 / 14 / 16 / 20 / 24，没有半像素；间距落到 2 / 4 / 6 / 8 / 10 / 12 / 16 / 20 / 24 / 32 / 48；圆角定为小件 6、控件 8、卡片 12、浮层 14；阴影只剩三级（无、悬停细线、浮层）。两份浅色变量同步改、仍然一致。
- **控件扁平化**：按钮去掉内高光和投影，主按钮从渐变改成纯色，输入框去掉内阴影；卡片不再投影，靠表面色差分层。
- **表面色重调**：深色四级表面，内容区比侧栏略深；浅色侧栏从偏蓝灰的 `#e8e8ed` 换成中性的 `#efeff1`。
- **对话页**：正文 14px、行高 1.65、行宽 760；用户消息是不带阴影的浅底块；工作区标签改成正文字体的灰字，只在别的机器上才写机器名，去掉 `this machine`；Todos 托盘、输入框、工具栏合成一个圆角整体；标题下拉不再在点选后留下蓝色焦点环。
- **中控台**：三张数字卡并成标题下一行「N 在跑 · N 等你 · N 失败」；页头只留「新对话」，「全部对话…」挪进标题下拉；右栏卡片去掉描边环，选中改成选中底色，次要按钮改成文字按钮，命令预览去掉深色框。
- **细节**：菜单和右键菜单悬停从整行蓝底改成浅灰；工作区卡片选中改成选中底色；侧栏未选中项退到次级灰；空状态图标放进柔和的圆角底块；弹窗进场带一点回弹。
