## b2 · 直接能用、说法一致

对应原则 2（直接能用）、4（一致）、6（对用户负责）。界面变化主要在文字上，截图只拍有变化的地方。

- **错误说人话**（问题 8）：认不出的错误原来直接显示 stderr 第一行，比如 `Error: ENOSPC`、`ECONNRESET`。现在磁盘满、缺程序、连接被重置、没有权限都翻成一句话，中英两套词表一起改。
- **统一用词**（问题 9）：对话外面的“会话”统一叫“对话”，“审批”统一叫“批准”，待处理事项去的地方统一叫“中控台”，不再说一个没有独立页面的“收件箱”。bot 自己的收件箱和线程是另一回事，保留原名。
- **主流程去术语**（问题 10）：新建工作区里的“独立分支”改成“在副本里改：另放一份代码副本、开一个新分支，原目录不受影响”，“主仓正 checkout 着这个分支”改成“原目录正在用这个分支”；开始清单第一步从“运行时”改成“Claude Code 或 Codex”；销毁、冻结副本时说清目录、分支和没提交的改动会怎样；结束后台任务不再提 TERM。
- **派出去的活跟着派活的会话走**（问题 11）：会话用 `send_prompt` 派活又没写权限模式时，沿用自己的模式，不再让用户替别人开的会话逐条点批准；会话用 `create_workspace` 建的工作区默认挂在它所在的工作区名下，列表里折叠在父工作区下面（`standalone: true` 可以不挂）；只读的调度工具（状态、列表、记录、日志、等待）对所有会话自动放行。
- **破坏性操作**（问题 12）：冻结可以随时解冻，不加确认，只把说明写清楚。其余几处（删排队消息、删评审评论、释放认领）影响小，这批没动。

## b6 · 审阅和撤销

- **错误默认说人话**（问题 6）：`InlineError` 默认把原始错误翻成一句话，原文折进「详情」；新增 `toast_error`，原文只在悬停和控制台里。全应用约 150 处直接拼 `{e}` 的地方改走它们（机器页、智能体页、账号与额度页另有约 65 处）；对话里走英文那套。用量页的失败原因写成「服务繁忙（529）」「机器的磁盘满了」，同一说法合并计数，原文进「详情」。有意保留原文的只有本来就是原始输出的地方（仿真日志、工具的报错输出、git 操作输出的折叠块）。
- **机器页只做一件事**（问题 7）：「机器与组网」只剩页头的「添加机器」、机器表，和底下一小组「多机协作」（一个开关，桌面端再加一行「Blazar 运行在 这台电脑 · 更改…」）。团队组网、签发、邀请、邀请记录收进一个「邀请同事 / 加入团队」弹窗，EasyTier 配置、RPC 门户、network_secret、easytier-cli、凭据文件只出现在弹窗里各组的「高级…」下面。同一样东西一律叫「机器」（原来还有节点、对端、开发机、可见节点），「枢纽」只留在高级说明里。原来的「开发机」这个角色改叫「可派活」（「可派活 / 个人电脑」），这个叫法是这一批定的，看着别扭再换。
- **“智能体”只指一样东西**（问题 8）：「角色档案」一律叫「智能体」；「运行时」那一页改叫「账号与额度」，界面上不再出现“运行时”这个词，筛选、表单、用量表头直接写「Claude Code / Codex」；四个标签页的页标题分别是「智能体 / 技能 / 账号与额度 / 用量」，不再都叫“智能体”。路由没变，命令面板里旧词留作搜索关键词。
- **撤销统一**（问题 15 的一部分）：智能体档案的单条和批量归档都改成 5 秒撤销（原来批量要确认），提示里写明「正在运行的任务会被取消」；bot 页释放认领也改成 5 秒撤销，提示「别的 bot 现在可以占用它」。撤销真正发出却失败时，提示写清楚是哪一步没成（「没归档」「没释放」），不再都写“没删掉”。

验证：`cargo fmt`、`leptosfmt`、全工作区的 clippy、`cargo test --workspace`（1015 个，0 失败）、导航测试都通过。在开发实例里核对过：机器页正文里 EasyTier、network_secret、节点、RPC 出现次数都是 0，只有「添加机器」「邀请同事」「多机协作」；智能体页里没有「角色档案」和「运行时」，标签条是「智能体 · 技能 · 账号与额度 · 用量」；用量页正文里没有 stderr、ENOSPC、API Error；0 条控制台错误。三层弹窗（邀请 → 高级 → EasyTier 配置）的焦点和 Esc、机器页新页头的样子还没在界面上细看。
