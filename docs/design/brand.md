# Blazar 品牌规范

一页纸，够用就好。目标是克制：一个强调色，一个图形母题，其余都交给中性灰和内容。

## 名字和意象

Blazar（耀变体）是喷流正对着我们的活动星系核。图形就取这个意象：一道**地平线弧**，底部开口；两道**喷流**从弧里射出，略微向外张开。弧代表一台台机器和它们的边界，喷流代表从里面发出去的工作。

## 强调色：靛蓝

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 强调色 `--accent`（主按钮、选中、焦点环、运行中的圆点、图表选中柱、链接） | `#5e5ce6` | `#7170ff` |
| 主按钮悬停 `--primary-hover` | `#6e6cf0` | `#8584ff` |
| 品牌色（应用图标、侧栏 logo、关于页、favicon；不随主题变） | `#5e5ce6`，图标上自上而下 `#6a68ec → #5452dc` 的轻微渐变 | 同左 |

- 同一个色相，深色调亮一档是为了对比度：浅色白字 5.06:1，深色在画布上 4.61:1、白字 3.84:1（原来的系统蓝分别是 3.65、4.86、3.65）。
- 强调色只用在“你现在要看这里”的地方：主操作、选中、焦点、正在运行。不用它做装饰、大面积底色或插图填充。
- 状态色仍各司其职：橙色是等你处理，红色是失败，绿色是在线或成功。它们不是品牌色。
- 选区、选中项底色、输入框聚焦描边都从强调色派生（同一色相的低透明度），不再有第二种蓝。

## 图形母题：地平线弧和两道喷流

坐标都在 1024 的网格上（`apps/desktop/icons/src/`）：

- 弧：圆心约 (512, 493)，半径 208，从左下 (365, 640) 经过顶部到右下 (659, 640)，底部开口约 90°，线宽 46，圆头。
- 喷流：两条，从 (471, 502) 到 (449, 714)、从 (553, 502) 到 (575, 714)，线宽 54（比弧略粗），圆头，向外张开约 6°。
- 只有这两种笔画，不加点、不加星、不加光晕。

三种用法：

1. **方块标志**（应用图标、侧栏 logo、关于页、favicon）：靛蓝圆角方块（圆角约为边长的 22%），白色的弧和喷流。代码里是 `components::brand::tile()`。
2. **单色线条**（菜单栏图标）：只有弧和喷流，跟随系统的模板图标着色。
3. **空状态**：页面自己的 24px 线条图标放在中间，外面一道 1.5px 的灰色地平线弧（`--border-strong`），下面两道 2px 的强调色短喷流（`components::brand::HORIZON`）。空页面上只有这两笔是彩色的。

源文件：`blazar-brand.svg`（应用图标，靛蓝方块）、`blazar-dark.svg` / `blazar-light.svg`（深浅底上的方块，弧是前景色、喷流是强调色，给 README 和文档用）、`blazar-glyph.svg`（单色线条）。改了源文件之后，用 `node scripts/render-icon.mjs icons/src/blazar-brand.svg icons/icon.png 1024`（在 `apps/desktop` 下）出图，再 `cargo tauri icon icons/icon.png -o icons` 生成各尺寸。

## 文字

- 产品名只写 **Blazar**，首字母大写，不加“AI”“Studio”之类的后缀。
- 一句话介绍：把本地和远端机器上的代码与 AI 编码智能体放进同一个桌面工作台。
- 字体、字号和中文排版见 [product-north-star](../product-north-star.md) 和 `crates/web/style/tokens.css`。品牌不另外引入展示字体。

## 不要做的

- 不要再加第二个强调色，也不要用渐变按钮或渐变文字。图标上那层渐变是唯一的例外，而且要轻到几乎看不出来。
- 不要把标志拉伸、描边、加阴影、换颜色（菜单栏模板图标除外）。
- 空状态不要画场景插图或吉祥物；母题加页面图标就够了。
